تثبيت قاموس مصوّر على الحاسوب
==============================
1) ثبّت Node.js من https://nodejs.org (النسخة LTS).
2) افتح الطرفية (Terminal / CMD) داخل هذا المجلد ونفّذ:
     npm install
     npm start          <- لتشغيل التطبيق مباشرة
     npm run build      <- لإنشاء ملف تثبيت (exe / dmg / AppImage) داخل مجلد dist
